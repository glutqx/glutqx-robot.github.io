=====================
战队网站 使用手册（零基础版）
=====================
适用：每一届接手队员，不需要懂编程、不需要专业知识

一、基础说明
1. 打开方式：所有 .html 文件，双击就能用浏览器打开查看/编辑
2. 编辑工具：电脑自带「记事本」即可，不用装任何软件
3. style.css 是全局样式文件，全程不要打开、不要修改

二、文件目录规则（严格遵守，避免图片空白、网页损坏）
仓库根目录
├─ 全部html网页文件（首页、成员、兵种详情）
├─ style.css 样式文件（禁止修改）
├─ 新手使用指南.txt
└─ assets/ 【所有图片统一存放】
   ├─ 机器人图片：英雄.png、工程.png、步兵.png、哨兵.png、无人机.png、飞镖.png、雷达正面.png
   └─ avatars/ 队员头像图片

三、日常修改操作（照着步骤做）
1. 修改文字（战队简介、成员姓名、兵种介绍）
右键网页文件 → 打开方式 → 记事本，直接替换中文文字，Ctrl+S保存

2. 更换图片（机器人图、队员头像）
1）本地打开assets文件夹，把新图片重命名和旧图片一模一样（后缀.png保持一致）
2）同名覆盖旧图片，上传assets文件夹到GitHub，网页自动加载新图

3. 新增队员
打开members.html，复制一整块 <div class="member-card"> 模板，粘贴到下方
修改头像路径 assets/avatars/xxx.png、姓名、职位、简介即可

4. 修改顶部导航栏目
只修改index.html里<header>导航文字，修改完成后，复制整段<header>代码，替换所有html页面的顶部导航

四、GitHub上传更新步骤
1. 登录仓库页面 → Add file → Upload files
2. 拖拽修改后的html文件 / assets文件夹 上传
3. 填写提交备注，点击Commit changes
4. 等待1-3分钟，GitHub Pages自动重新部署网站

五、绝对禁止操作（弄坏网站）
1. 禁止重命名、删除任何html文件、assets文件夹
2. 禁止移动assets文件夹内图片位置
3. 禁止打开修改style.css文件
4. 图片文件名、文件夹不要使用中文、空格、特殊符号

六、换届交接说明
完整打包整个网站文件夹，连同本使用文档，完整交给下一届队员
